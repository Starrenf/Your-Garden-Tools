# Your Garden Tools — React + Vite

Broncode voor de publieke website van **Your Garden Tools**.

## Lokaal testen

Lees [README-LOKAAL.md](README-LOKAAL.md) voor installatie en testen.

Korte start:

```bash
npm install
npm run dev
```

De website opent standaard op http://localhost:5173.

## Functies

- Responsive publieke website met pagina's Home, Diensten, Werkwijze en Contact
- Liquid Glass-huisstijl en Toro-hoofdfoto
- Geen login, database of opslag van klantgegevens

## Technisch

- Vite + React, statische build
- `scripts/`: buildstappen en reconstructie van delen van de broncode
- `source-parts/` en `asset-parts/`: nodig voor de build
